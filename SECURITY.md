# Security and privacy

This repository is a public portfolio case study. It must never contain credentials, private deployment configuration, personal records, confidential stakeholder material or implementation secrets.

If you find a security or privacy issue, do not open a public issue. Email [hello@nwhite.systems](mailto:hello@nwhite.systems?subject=SAFA%20ProMax%20security%20report) with a concise description and safe reproduction details.
